ICKAB Advanced Audit & Login History

Login history, failed login monitoring, session visibility, location tracking and configurable create/modify/delete auditing for Odoo 18.

Maintained by ICKAB · ickab.mx

Access monitoring

Tracks successful logins, logout history, failed attempts, IP address, browser, operating system and session duration.

Configurable audit

Only models enabled in Model Log Configuration are audited. Create, Modify and Delete can be controlled independently.

Related documents

Supports related line tracking for Sales, Purchases, Invoices and Stock Pickings.

Administrator security

Audit history, failed logins and configuration are restricted to system administrators.

  • Stock Picking includes Stock Move and Stock Move Line when related models are enabled.
