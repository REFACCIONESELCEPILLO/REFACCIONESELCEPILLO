Odoo Product Creation Restriction/ Product Create Option Disable App

Odoo product creation restrict app helps to restrict quick product creation options in sales, purchase, invoice, and vendor bills.

Restrict Product Creation

Users can not create products directly from sale orders.

Create Products From Product and Product Variant

Users can create product from products and products variant menus.

Visible Created Products

Visible created product in order line.
