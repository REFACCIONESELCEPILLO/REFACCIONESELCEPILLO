# ICKAB Label Studio 18.0.5.4.0

- Label Studio conserva la responsabilidad exclusiva de diseñar, guardar y previsualizar.
- El diseño directo se entrega a ICKAB Direct Print en milímetros, sin escoger lenguaje,
  DPI objetivo ni transporte.
- Las imágenes conservan su fuente original para que Direct Print las procese según la
  impresora realmente seleccionada.
- El exportador ZPL propio de Studio se conserva para exportación/descarga; no determina
  el lenguaje de una impresión realizada por Direct Print.
- La integración sigue siendo opcional: Studio puede instalarse y usarse sin una
  dependencia dura de Direct Print.

- El flujo estándar **Imprimir etiquetas** de Inventario usa las cantidades reales
  de los movimientos/operaciones cuando el wizard proviene de una recepción o entrega.
  El usuario puede seleccionar un diseño Studio y Direct Print realiza la impresión.

## Integración de impresión

La impresión física desde Label Studio requiere ICKAB Direct Print. El diseñador no selecciona lenguaje, DPI, transporte ni impresora. Las funciones explícitas de importación/exportación siguen siendo herramientas de diseño, no una ruta paralela de impresión.
