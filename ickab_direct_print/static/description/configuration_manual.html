ICKAB Direct Print

Guía de configuración para usuarios — instalación inicial sin conocimientos técnicos.

Objetivo: conectar una PC con Odoo para que pueda imprimir directamente en etiquetas, tickets o documentos sin descargar archivos manualmente.

Antes de empezar

Necesitas una PC Windows con acceso a Odoo y a las impresoras que utilizará. La impresora USB debe estar instalada en Windows; una impresora de red debe ser accesible desde esa PC.

Instalación en 5 pasos

1

Crear el equipo en Odoo

Abre Direct Print → Configuración → Equipos / Agentes, pulsa Nuevo, escribe un nombre fácil como PC MOSTRADOR y guarda.

2

Generar el código de instalación

Dentro del equipo pulsa Generar código de instalación. Odoo mostrará un código de 8 números válido durante 15 minutos.

Para una instalación normal no necesitas copiar UUID ni Token. Esos datos están en Información avanzada.
3

Ejecutar el instalador en Windows

Descomprime el ZIP del agente en C:\ICKAB\PrintAgent y haz doble clic en INSTALAR.bat. El asistente revisará requisitos y te pedirá solamente la URL de Odoo y el código de 8 números.

4

Confirmar que el equipo está En línea

Regresa a Direct Print → Configuración → Equipos / Agentes. El estado debe cambiar a En línea. Odoo llenará automáticamente plataforma, nombre del equipo, versión del agente y última conexión.

5

Revisar y configurar las impresoras

Pulsa Impresoras. Clasifica cada impresora según su uso y define transporte, lenguaje, DPI y papel.

Primera prueba

  1. Confirma equipo En línea.
  2. Abre la impresora.
  3. Pulsa Enviar prueba.
  4. Abre Direct Print → Cola de impresión.
  5. Confirma que el trabajo termine en Impreso.
  6. Confirma la salida física.

Si algo no funciona

En la PC ejecuta DIAGNOSTICO.bat. El asistente revisa conexión con Odoo, autorización, impresoras detectadas y sincronización.

Equipo Fuera de línea: inicia el agente y revisa conexión a Odoo.
No aparecen impresoras: verifica que estén instaladas en Windows y ejecuta el diagnóstico.
Código vencido: genera uno nuevo en Odoo.
Trabajo en Error: abre el trabajo y revisa el mensaje de error.

Odoo.sh y on-premise

El procedimiento para el usuario es el mismo. El agente inicia la conexión hacia Odoo, por lo que Odoo.sh no necesita acceso directo a USB o a la red privada de la sucursal.

UUID, Token y capacidades JSON son información técnica para administradores y no forman parte de la instalación normal.

¿Qué dirección de Odoo debo usar?

Usa la misma dirección con la que entras a Odoo desde la PC donde instalarás el agente. Puede ser:

  • Servidor local: http://192.168.56.10:1902
  • On-premise con dominio: https://ickab.mx
  • Odoo.sh / nube: https://miempresa.odoo.com

Puedes copiar la URL completa desde el navegador; el instalador quitará automáticamente /web, parámetros y fragmentos.
