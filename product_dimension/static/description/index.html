Configurador dimensional

Configura productos por dimensiones y genera componentes exactos para fabricación

Solución integrada desarrollada y mantenida por Ickab.

Configuración funcional

  • Cálculo de venta por área, perímetro o unidad.
  • Búsqueda de valores por referencia interna o nombre.
  • Resolución genérica de atributos y variantes dinámicas.
  • Lista de materiales dinámica con los componentes seleccionados.
  • Órdenes de fabricación con cantidades dimensionales exactas.
  • Solicitudes de cotización por proveedor, variante y tarifa configurada.

Flujo resultante

Cotización configurada → orden de venta → lista de materiales dinámica → orden de fabricación → abastecimiento y compra de componentes exactos.

La lógica se basa en las relaciones configuradas entre atributo, valor, componente y proveedor. No depende de nombres fijos de atributos.
